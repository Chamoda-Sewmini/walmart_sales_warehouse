# 🛒 Walmart Sales Data Warehouse & Business Intelligence

### Data Warehouse • ETL • OLAP • Power BI

</div>

This project develops a Data Warehouse and Business Intelligence (DWBI) solution using Walmart sales data.

The project integrates multiple data sources, including CSV and JSON files, performs data preparation and ETL, designs a dimensional Data Warehouse, and provides analytical insights through OLAP operations and Power BI dashboards.

## 📊 Data Sources

| Source          | Description                       |
| --------------- | --------------------------------- |
| `train.csv`     | Historical Walmart sales          |
| `features.csv`  | Economic indicators and markdowns |
| `stores.csv`    | Store information                 |
| `holidays.json` | US public holiday data            |
| `test.csv`      | Forecasting/test data             |
